# Редактор программы ТРЭК
Откройте index.html в браузере на компьютере. Файлы проекта должны лежать в одной папке. Xcode и интернет для редактирования не требуются.

Выберите раздел, откройте запись или нажмите «Добавить». В докладе можно выбрать несколько авторов, задать порядок и оставить время пустым. Кнопка «Сохранить» сохраняет изменения в этом браузере. Перемещение папки, очистка данных браузера и приватный режим могут повлиять на сохранность черновика.

Для переноса изменений нажмите «Скачать программу», замените файл Pulse/program.json в исходниках проекта iOS и пересоберите приложение. Экспорт служит также резервной копией. Раздел «Конференция» редактирует метаданные программы. Текст интерфейса и логотип задаются отдельно в приложении.

Начальное содержимое находится в demo.js. Чтобы начать новую рабочую копию с другого совместимого program.json, скопируйте папку редактора и замените значение константы demo содержимым JSON до первого открытия новой копии.

## Импорт PDF
Нажмите «Импорт PDF», выберите файл и дату для страниц без явно указанного года/даты. PDF обрабатывается на компьютере через PDF.js. Файл никуда не отправляется. Проверьте порядок извлечённых строк, особенно в многоколоночных документах. Нажмите «Распознать», проверьте карточки и затем «Добавить в программу». Повторный импорт добавляет новые записи.

Поддерживаемый формат строк:
19 июня 2026
Зал: Основной
09:00–10:00 Сессия: Трансрадиальный доступ
09:00–09:20 Выбор доступа
Докладчики: Иванов Иван Иванович; Петров Пётр Петрович
Доклад: Обсуждение без точного времени

Разбор использует правила для дат, времени, заголовков и явно подписанных авторов. Строки продолжения сохраняются в описании. Неопознанный текст до первой сессии остаётся в поле исходного текста. Сканированные PDF требуют предварительного OCR. После импорта можно исправить все записи обычными формами редактора и скачать program.json.
